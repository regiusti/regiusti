# Renan Giusti — Portfólio

Portfólio one-page: desenvolvedor de sistemas e sites, gerente de projetos e business partner.

- `index.html` — página única, sem dependências de build (HTML + CSS + JS puro).
- Os "prints" dos projetos são mockups fiéis das telas, com **números borrados e logos ocultados** por confidencialidade. Para trocar por prints reais, substitua o conteúdo de cada `.shot` por uma `<img>`.
